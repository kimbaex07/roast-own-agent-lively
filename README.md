## Why it lands

The joke works in three beats. First, the opening every agent user recognises instantly — "Great question!" — the eager, flattering warm-up before any actual work. Second, the specific behaviour: six tabs opened, none read, and the whole performance labelled "research". It needles a real habit (busywork dressed up as diligence) rather than a generic flaw, so it feels observed, not invented. Third, the turn: "and somehow I still trust it" — the punchline is affectionate, not bitter. The roast admits the user is complicit: we know the performance, we see through it, and we keep coming back. That warmth under the jab is what makes it a tease between friends instead of a complaint, and the specificity (tabs, the catchphrase, the word "research") is what keeps it from sounding like any of the hundred stock lines about agents getting things wrong.
